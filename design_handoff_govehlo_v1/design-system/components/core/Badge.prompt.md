Compact status pill for labelling states. Amber/money variants reserved for monetary context.

```jsx
<Badge variant="default">Shared car</Badge>
<Badge variant="success" dot>Paid</Badge>
<Badge variant="money">52 kr owed</Badge>
<Badge variant="pending" dot>Pending</Badge>
<Badge variant="error">Overdue</Badge>
<Badge variant="forest">Active</Badge>
```

**Variants:** `default` (mist/green), `success` (leaf — paid/confirmed), `money` (amber tint — amounts),
`pending` (warm yellow), `error` (red tint), `neutral` (gray), `forest` (solid green).
