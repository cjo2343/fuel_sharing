Small pill label for categories and metadata filters, with optional dismiss control.

```jsx
<Tag label="Shared car" />
<Tag label="Fuel" color="amber" />
<Tag label="Settled" color="leaf" />
<Tag label="Lars" color="neutral" onRemove={() => {}} />
```

**Colors:** `default` (mist/green), `amber` (money/fuel), `leaf` (positive/settled), `neutral` (gray).
